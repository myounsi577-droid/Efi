efibuild-1.0.0.zip — archive complète efibuild.pyz — exécutable seul, 68 Ko Code source du projet

Python 3.9 ou plus récent, rien d'autre. Testé sur Ubuntu, macOS et Windows.

Ce que la commande fait en plus

  • Télécharge OpenCore, les SSDT et chaque kext depuis sa source officielle
  • Génère numéro de série, MLB et UUID avec macserial
  • Écrit le config.plist et le valide avec ocvalidate
  • Récupère l'image de récupération Apple via macrecovery
  • Sauvegarde, formate en FAT32 et remplit la clé USB

Sur téléphone et tablette

  • Cette page fonctionne partout et s'installe sur l'écran d'accueil (Partager → Sur l'écran d'accueil sur iOS, Installer sur Android).
  • Android : Termux (F-Droid) → pkg install python, puis python efibuild.pyz. L'EFI se construit vraiment.
  • iPhone / iPad : a-Shell exécute Python 3 ; iSH émule x86 et fait tourner en plus macserial et ocvalidate.
  • Sur ARM, les numéros de série et la validation sont ignorés : l'outil le dit et le reste est construit normalement.
